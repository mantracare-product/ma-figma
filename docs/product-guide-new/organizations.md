# Organizations

## What this page is for
The **Organizations** screen allows system administrators to manage corporate accounts, parent entities, or multiple company branches from a single unified control panel.

---

## Features on this page

### 1. Active Organizations list
- **What it does:** Displays all corporate entities or branch locations configured under your master portal account.
- **Why it helps you:** Keeps separate branches organized. Each organization operates with its own distinct phone numbers, processes, databases, and billings.
- **How to use it:** Scroll through the organization rows. Click the active branch row to view company detail cards or switch active accounts.

### 2. Corporate Detail cards
- **What it does:** Displays company info, contact email, primary domain, and assigned processes count.
- **Why it helps you:** Provides a quick overview of branch configurations and active workloads.
- **How to use it:** Read the summary information panels.

### 3. Add Organization Popup Form
- **What it does:** Opens a creation form requiring Company Name, Industry, Website Domain, and timezone settings.
- **Why it helps you:** Allows managers to spin up new branches or business divisions in seconds.
- **How to use it:** Click the blue **+ Add Organization** button, fill in the branch details, and click **Save**.

---

## Common workflows

### Workflow A: Adding a new clinic branch location
1. Go to the **Organizations** page and click **+ Add Organization**.
2. Type Company Name "Mantra Care - Downtown Clinic", select "Healthcare" industry, and input the web address.
3. Click **Save**. The branch is created and becomes selectable in the header switcher.
