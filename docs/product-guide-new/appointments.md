# Appointments & Calendar

## What this page is for
The **Appointments** screen manages your calendar booking logs and schedules. It displays metric cards, lists booked sessions, offers interactive calendar views (Day, Week, Month, Schedule), and hosts rescheduling parameters.

---

## Features on this page

### 1. Booking Summary Cards
- **What it does:** Displays cards tracking Total Bookings, Upcoming slots, Completed sessions, and Canceled sessions.
- **Why it helps you:** Tracks customer booking volume and cancellation rates.
- **How to use it:** Read the summary cards at the top of the appointments dashboard.

### 2. Appointments Log table
- **What it does:** A detailed spreadsheet listing every individual booking: Client Name, Service Selected, Assigned Staff, Date, Time, and Status.
- **Why it helps you:** Useful for scrolling through upcoming check-ins or confirming if a client has an active slot.
- **How to use it:** Search client names, or filter by Staff and Service columns.

### 3. Interactive Calendar Planner (Views)
- **What it does:** Displays appointment blocks on a calendar layout. You can switch between Day, Week, Month, and Schedule (chronological list) views.
- **Why it helps you:** Provides a visual planner of daily client schedules, helping you spot double-bookings or empty slots.
- **How to use it:** Click **Day**, **Week**, or **Month** buttons. Double-click any time slot to manually book a session, or drag an appointment block to another slot to reschedule.

### 4. Create Event Popup Form
- **What it does:** Opens a manual slot creation form with fields for Event Name, Start Date/Time, End Date/Time, Calendar target, Location, and Attendees.
- **Why it helps you:** Allows team members to block out slots for personal time, company meetings, or manually book phone appointments.
- **How to use it:** Click the blue **+ Create Event** button or double-click a date cell, fill in the form, and save.

## Common workflows

### Workflow A: Rescheduling an appointment on the calendar
1. Go to the **Calendar** tab and select **Week** view.
2. Locate the "Sarah Johnson - Dental Cleaning" block on Tuesday at 10:00 AM.
3. Click and hold the block, drag it down to 02:00 PM, and release.
4. The system updates the appointment, alerts Dr. Martinez, and triggers the AI to send a SMS notification update to Sarah.

### Workflow B: Auditing cancellations
1. Click the **Filters** button on the appointments log.
2. Select "Canceled" from the **Status** drop-down.
3. Review the list of canceled slots. Check the assigned staff column to see if cancellations are higher for specific service lines.
